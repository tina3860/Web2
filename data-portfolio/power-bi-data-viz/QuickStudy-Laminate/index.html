QuickStudy Laminate

View Visual

Problem

As part of my grad program, I've been working through everything from Association Rules and Decision Trees to Neural Networks and Sentiment Analysis and I realized my notes were scattered across 8+ Jupyter notebooks, lecture slides, and scribbled margins.

Solution

So I built a 4-page QuickStudy laminate reference guide that consolidates everything:

A Master Model Index that includes 19 algorithms, each with a use case, output type, and "when to use" decision rule.
Full Python syntax for every model (sklearn, Keras, NLTK, VADER, TextBlob).
Real examples pulled directly from class notebooks.
Formulas with plain-English explanations (Entropy, Bayes' Theorem, Ridge vs. Lasso, VIF)
A quick decision flowchart: labeled data? → type of target? → right algorithm.

Impact

Building this forced me to actually understand the connections between concepts — not just run the code.

If you're in an applied ML program or transitioning into data analytics, I can't recommend this kind of synthesis exercise enough. You learn more building the cheat sheet than using it.
